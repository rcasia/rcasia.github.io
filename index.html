Senior Software Engineer

I'm Ricardo Casía Moka, a Senior Software Engineer at Thoughtworks. I architect scalable systems, lead technical initiatives, and mentor development teams for enterprise clients. I'm passionate about clean code, test-driven development, and building software that stands the test of time.

I maintain several open source projects focused on developer tooling. These include neotest-java and neotest-bash, test adapters for Java and Bash workflows in Neovim, and ascii-ui.nvim, a library of ASCII-based UI components for Neovim plugins.

Through this blog, I share technical insights, engineering practices, and tool configurations to contribute to the developer community.
